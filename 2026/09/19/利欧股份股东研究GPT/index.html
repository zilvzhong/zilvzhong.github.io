一、先说结论

我先给你一个非常重要的结论：

不能把“外资机构新进十大股东”直接等同于“未来上涨”。

这些机构的持仓有可能：

  • 自营投资
  • QFII
  • 客户资金
  • 多策略基金
  • 对冲策略
  • 指数/量化
  • 套利
  • 可转债/衍生品对冲
  • 短中期交易

所以“某机构新进”真正有价值的是：

它是不是连续增持？

而不是：

它是不是第一次出现？

这一点对利欧股份尤其重要。

二、先搞清楚 UBS AG 到底是谁

UBS，中文一般叫：

瑞银集团

总部在瑞士，是全球大型金融集团。

但你在A股十大股东里面看到的：

UBS AG

不要简单理解成：

“瑞银集团总部自己拿几十亿资金买股票。”

它更准确的含义是：

一个境外合格机构投资者的证券账户/持股主体。

UBS早在2003年就是中国第一批获得QFII资格的海外机构之一。证监会历史名单中，UBS AG列为瑞士QFII。(中国证券监管委员会)

而且UBS自己也明确说明：

UBS AG可以通过QFII和沪深港通参与中国A股。

(Switzerland)

三、UBS真正厉害的地方不是“买股票”

UBS在中国实际上有几个体系：

① UBS AG

境外母体。

② UBS Securities

瑞银证券。

它是中国首家外资全牌照证券公司之一，为机构、个人、企业以及QFII提供证券服务。(Switzerland)

③ UBS Asset Management

瑞银资产管理。

涉及：

  • 股票
  • 固收
  • 多资产
  • 指数
  • 另类投资
  • 全球资产配置

所以：

“UBS AG持有某只A股”不能简单理解成瑞银研究员看好这家公司。

可能是不同投资组合中的一个仓位。

四、UBS有一个特别值得你注意的特点

UBS在中国A股市场参与时间非常长。

它不仅做：

股票多头

也参与：

证券出借、融资融券、QFII等业务。

UBS自己披露过，QFII新规实施后，其QFII账户持有的中国股票可以参与证券出借；2020年QFII两融业务上线时，UBS也完成了相关融券交易。(Switzerland)

所以：

UBS出现 ≠ 单纯“看涨”。

但是：

UBS连续增持

价值就明显提高。

五、再看利欧股份这次UBS

2026Q1：

UBS AG

1114.39万股

占总股本：

0.16%

到了2026Q2：

1929.10万股

占：

0.28%

增加：

814.71万股

增幅：

73.11%

(搜狐股票)

这比“新进”更加有意义。

因为：

UBS不是第一次出现，而是在Q1已有仓位基础上继续增加。

所以利欧股份这里我给UBS的信号强度：

中等偏强

六、香港中央结算反而是这次最重要的信号

这一次真正最大的变化不是UBS。

而是：

香港中央结算有限公司

Q1：

7163.25万股

Q2：

1.69793亿股

增加：

9816.07万股

增幅：

137.03%

占总股本：

2.51%

占流通股：

2.90%左右

(新浪财经)

这个数量远远超过其他几家。

七、但香港中央结算到底是谁？

这个一定要搞清楚。

香港中央结算 ≠ 一家基金

它本质上是：

香港市场的中央结算/托管体系中的名义持有人。

中国证监会解释过，香港结算可以作为名义持有人持有通过相关机制交易的A股；香港结算也为中央结算系统参与者提供结算、交收和托管服务。(中国证券监管委员会)

因此：

香港中央结算增加9816万股

不能解释为：

“一个机构买了9816万股。”

正确理解应该是：

通过香港结算体系登记的实际投资者/机构资金，对利欧股份的持仓显著增加。

里面可能包含多个不同投资者。

八、这也是为什么我认为“香港中央结算 + UBS”组合更值得关注

单独：

香港中央结算 ↑

你不知道是谁。

单独：

UBS ↑

也不能确定投资逻辑。

但是如果：

香港中央结算大幅增加

  • UBS继续增持
  • 阿布达比新进
  • 中信资管香港新进
  • 高盛新进

同时发生。

这就开始形成：

“境外机构资金群体性进入”的迹象。

当然仍然不能确定这些账户彼此之间存在一致行动。

公司自己也明确披露：

除已知关联关系外，公司未知其他股东之间是否存在关联关系或一致行动关系。

(新浪财经)

九、阿布达比投资局到底是什么？

ADIA

即：

Abu Dhabi Investment Authority

中文：

阿布达比投资局

本质是：

阿联酋阿布达比酋长国的主权财富基金。

它的特点和普通基金不同。

它管理的是国家层面的长期资本。

所以当：

“阿布达比投资局－自有资金”

进入A股十大股东时，市场通常会比较关注。

但这里有一个非常关键的区别：

长期资金 ≠ 买入后一定长期持有

主权基金同样会：

  • 调仓
  • 再平衡
  • 行业配置
  • 估值切换
  • 风险管理

所以不能把它理解成“买了就不会卖”。

十、阿布达比在A股其实不是第一次玩

截至近期公开披露数据：

阿布达比投资局已经出现在大约：

67家A股公司

的已披露股东名单中。

而且它和：

  • 香港中央结算
  • UBS
  • 摩根士丹利
  • 高盛
  • JPMorgan

等机构存在较多共同持股。(上市公司股东库)

这点非常重要。

因为这说明：

这些机构经常出现在同一批大型/中大型A股公司的机构股东结构里。

所以利欧股份出现这种组合，并不意味着它们之间存在“联合坐庄”。

更合理的解释是：

同一类全球机构资金池正在关注中国A股。

十一、阿布达比过去新进A股后的表现怎么样？

这里我要非常谨慎。

因为公开披露只能告诉我们：

某个季度末它持有多少股。

但我们不知道：

它具体哪一天买的、平均成本是多少。

因此无法精确计算：

“阿布达比赚了多少钱”。

只能计算：

从首次披露时点到后续报告期/当前股价的区间收益。

这两个概念不要混淆。

十二、但我们可以用真实案例观察

例如2026Q1：

阿布达比投资局新进

  • 立讯精密
  • 万华化学
  • 京东方A
  • 三一重工
  • 三环集团
  • 生益科技
  • 复星医药

  • 安琪酵母
  • 伟测科技
  • 同有科技
  • 聚飞光电
  • 等

公开数据可以确认这一批持仓。(上市公司股东库)

这本身就说明：

阿布达比不是只买“妖股”。

它的组合非常分散：

资源 + 制造 + 消费 + 科技 + 金融 + 医药 + 周期

都有。

所以：

阿布达比进利欧股份，并不意味着它把利欧股份当成高确定性核心资产。

这点很重要。

香港中央结算增加 + UBS + 阿布达比同时出现。

这非常值得研究。

十四、但这种组合出现后并不代表股票一定上涨

例如同有科技这个案例，本身就说明：

机构进入只是资金行为，不是未来收益保证。

这也是为什么我不建议我们简单做：

这种策略。

十五、中信证券资产管理（香港）又是什么？

这个名字容易让人误解。

它不是：

“中信证券自营资金”。

它的名字是：

中信证券资产管理（香港）有限公司－客户资金

也就是说：

更接近资产管理/客户资金账户。

这次利欧股份：

1359.34万股

占总股本：

0.20%

Q2新进。

(新浪财经)

十六、这个机构的特点

公开股东数据中，中信证券资产管理（香港）客户资金已经出现在：

150多家A股公司

的已披露股东名单中。

它与：

  • UBS
  • 香港中央结算
  • 高盛
  • 摩根士丹利
  • JPMorgan

等机构有大量共同持股。(上市公司股东库)

所以：

中信资管香港新进

我不会给“极强信号”。

因为它本身就是一个：

比较分散的全球/跨境资产管理账户体系。

十七、高盛又是什么情况？

你看到：

高盛国际－自有资金

这和：

高盛公司

高盛资管基金

不是完全相同的账户。

它属于：

Goldman Sachs体系下的自有资金账户。

高盛本身也是中国早期QFII之一，证监会历史名单显示高盛公司于2003年取得QFII资格。(中国证券监管委员会)

十八、高盛新进的意义

利欧股份：

1341.47万股

占总股本：

0.20%

(新浪财经)

单看仓位：

并不大。

所以：

“高盛新进”

本身我不会给特别高的权重。

但是：

高盛 + UBS + 阿布达比 + 中信资管香港

四个账户同时进入十大流通股东，就不同了。

十九、我们真正应该统计的是“后续赚钱率”

你这个问题其实可以做成一个非常有价值的模型。

但必须先定义：

什么叫“赚钱”？

因为我们无法知道机构真实成本。

所以我建议采用：

方法A：披露日后收益

首次披露持仓的报告期末价格：

→ 后续30/60/90个交易日收益。

方法B：连续持有收益

如果下一季度：

机构：

继续持有/增持

那么计算：

Q1 → Q2

或者：

Q2 → Q3

的股价变化。

方法C：退出收益

如果下一季度退出十大股东：

计算：

首次出现 → 最后出现

期间股价变化。

二十、从这个角度看，最重要的其实不是“新进”

而是：

“新进 → 下一季度是否继续持有？”

这个指标的价值比“新进”高很多。

例如：

A

Q1：

UBS新进

Q2：

UBS继续增持

→ 强信号

B

Q1：

UBS新进

Q2：

UBS退出

→ 弱信号

C

Q1：

UBS新进

Q2：

持仓不变

Q3：

继续增加

→ 非常值得关注

二十二、这可能意味着什么？

有两种完全不同的解释。

解释A：机构开始价值重估

一些主动资金认为：

4～5元附近的利欧股份风险收益比开始改善。

因此：

  • UBS增加
  • ADIA进入
  • 高盛进入
  • 中信资管进入

同时指数资金退出。

这属于：

被动资金 → 主动资金接棒

这是比较积极的解释。

二十三、另一种解释

也可能是：

Q2大跌过程中

指数基金因为指数权重/组合调整卖出，

而海外账户因为：

  • 量化策略
  • 相对价值
  • 低估值
  • 短期交易
  • 行业轮动

进行买入。

那么：

这未必代表长期看好。

因此必须等Q3股东数据验证。

二十四、所以我现在最关心的是Q3

如果Q3出来：

香港中央结算

继续：

1.70亿 → 1.8亿/2亿

UBS

继续：

1929万 → 2200万/2500万

阿布达比

继续：

1803万 → 2000万+

高盛

继续：

1341万 → 1500万+

中信资管香港

继续持有甚至增加

那么这个信号的级别会明显提高。

二十五、反过来

如果Q3：

香港中央结算：

1.70亿 → 1亿

UBS：

1929万 → 大幅下降

阿布达比：

直接消失

高盛：

直接消失

中信资管：

直接消失

那么说明：

Q2的机构进入更可能是阶段性交易，而不是持续配置。

二十六、这就是为什么我暂时把利欧股份定义成

“机构开始关注，但还没有完成趋势确认”。

目前股价：

4.50

机构结构：

明显改善

但是技术面：

仍然处于4.30～4.80震荡区间。

所以：

机构数据领先

但是：

股价还没有确认。

二十七、把这几家机构按照“信息含金量”拆开

我个人不会给它们简单排名，但可以按可解释程度分类：

账户 我更关注什么
香港中央结算 资金规模最大，但无法知道最终投资人
UBS AG 已有持仓基础上继续增加，连续性很重要
阿布达比投资局 长期全球配置属性，但并非买入即长期持有
中信资管香港－客户资金 客户资产管理账户，策略可能较多元
高盛国际－自有资金 自营属性较明显，但单只股票仓位很小

所以对于利欧股份：

最值得跟踪的不是“谁的名字最响亮”。

而是：

谁在Q3继续加仓。

二十八、还有一个非常关键的数据

散户账户大规模退出

二十九、但是我不会现在直接告诉你“机构已经抄底成功”

因为还有一个反证：

2026Q2末利欧股份股价大约：

4.75元

而现在：

4.50元附近。

也就是说：

机构进入之后，股价目前仍然没有向上突破。

这说明市场尚未用价格验证机构持仓。

三十、所以我给你一个非常实用的“机构验证模型”

以后你看到：

UBS / ADIA / 高盛 / 中信资管 / 香港中央结算

进入某只股票，可以直接这样判断：

这才是高质量的机构跟踪。

三十二、最终结论

你这次发现的这个现象，我认为确实值得高度跟踪，尤其是：

香港中央结算 + UBS增持 + 阿布达比新进 + 中信资管香港新进 + 高盛新进。

2026Q2利欧股份的股东数据已经明确支持这些变化。(新浪财经)

但目前证据只能支持：

“境外/国际机构参与度明显提高”

还不能支持：

“这些机构已经形成一致性长期做多”

更不能直接推导：

“未来一定上涨”。
